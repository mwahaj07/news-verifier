# Specification: News Verification Agent (Phase 1 - MVP)

- **Spec Version:** 1.1.0
- **Status:** APPROVED & IMPLEMENTED
- **Architecture:** Single-Agent Autonomous ReAct with Circuit Breaker
- **Runtime:** Python 3.12+ / FastAPI / Google GenAI SDK (`google-genai`) / Tavily API

---

## 1. System Objective & Boundaries

### 1.1 Objective
Build an automated single-agent fact-checking service that ingests a news headline/claim, autonomously executes targeted web searches, and returns a deterministic, structured verification verdict with verifiable evidence URLs.

### 1.2 In-Scope (Phase 1)
- Ingesting single-claim text (10–500 characters).
- Generating neutral, entity-focused search queries.
- Querying live web sources via Tavily API (basic search depth, max 5 results).
- Strict adherence to JSON schema outputs via Pydantic models.
- Circuit breaker to prevent infinite tool-call loops and token drain (`maximum_remote_calls = 2`).
- Providing an HTTP REST API interface with automatic OpenAPI/Swagger documentation.

### 1.3 Out-of-Scope (Deferred to Phase 2+)
- Multi-claim article decomposition (checking full multi-paragraph articles).
- Multimodal analysis (reverse image/video forensics).
- Automated scraping of full web pages beyond snippets.
- Multi-agent debate / adversarial critic evaluation.
- User authentication, rate limiting, and persistent database storage.

## 2. Interface Contracts

### 2.1 Input Contract: `VerifyRequest`
Incoming HTTP `POST /verify` payload must adhere to:

| Field | Type | Required | Constraints | Description |
|---|---|---|---|---|
| `claim` | `string` | Yes | `min_length: 10`, `max_length: 500` | The raw news headline or rumor to verify. |

**Example Valid Input Payload:**
```json
{
  "claim": "NASA confirmed asteroid 2026-KX will hit the Atlantic Ocean tomorrow."
}
```

### 2.2 Output Contract: `VerifyResponse`
All responses must strictly validate against this schema:

| Field | Type | Required | Enum / Constraints | Description |
|---|---|---|---|---|
| `verdict` | `string` | Yes | `["TRUE", "FALSE", "MISLEADING", "UNVERIFIED"]` | Categorical fact-check verdict. |
| `confidence` | `integer` | Yes | `0 <= confidence <= 100` | Estimated confidence score. |
| `search_query_used` | `string` | Yes | Non-empty | The primary keyword query generated by the agent. |
| `explanation` | `string` | Yes | 2–3 sentences | Fact-based justification grounded ONLY in search evidence. |
| `sources` | `list[string]` | Yes | Valid URLs (empty list if UNVERIFIED) | Exact URLs present in search results supporting the verdict. |

**Example Output Payload:**
```json
{
  "verdict": "FALSE",
  "confidence": 95,
  "search_query_used": "NASA asteroid 2026-KX Atlantic Ocean impact warning",
  "explanation": "No records exist from NASA's Center for Near-Earth Object Studies (CNEOS) or any major wire service regarding an asteroid named 2026-KX. The agency's Sentry impact risk monitor reports zero imminent threats.",
  "sources": [
    "[https://cneos.jpl.nasa.gov/sentry/](https://cneos.jpl.nasa.gov/sentry/)",
    "[https://www.nasa.gov/planetarydefense/](https://www.nasa.gov/planetarydefense/)"
  ]
}
```

### 2.3 Tool Interface: `search_web`
The agent has access to one tool:
- **Function Name:** `search_web`
- **Input Parameter:** `query` (`string`, required) — Neutral search keywords.
- **Output:** Formatted string of top 5 results (`Title`, `URL`, `Snippet`) or error sentinel.
- **Sentinel Responses:**
  - Zero hits: `"OBSERVATION: ZERO_RESULTS_FOUND. Stop searching and output your verdict."`
  - Tool error: `"OBSERVATION: TOOL_ERROR (<error message>). Stop searching."`

## 3. Operational & Guardrail Rules

1. **Epistemic Humility (Grounding):**
   - The agent MUST NOT use pre-training memory to invent facts, events, or citations.
   - The agent MUST ONLY cite URLs that were explicitly returned in a `search_web` observation.
2. **Circuit Breaker (Maximum Remote Calls):**
   - Hard execution limit: `maximum_remote_calls = 2`.
   - The runtime must forcibly terminate the search loop after 2 tool executions, regardless of agent intent.
3. **Data-Void & Absence Heuristic:**
   - If an alleged public event (e.g., plane crash, disaster, national policy change) yields zero matching records after 1–2 searches, the agent must categorize it as `FALSE` (fabricated) or `UNVERIFIED`, never looping indefinitely.
4. **Deterministic Behavior:**
   - LLM generation temperature must be set to `0.0`.

## 5. Acceptance Test Criteria

To verify compliance with this specification, the system must pass the following cases:

- [x] **Test 1 (Input Validation):** Sending `{"claim": "short"}` (less than 10 chars) returns HTTP `422 Unprocessable Entity`.
- [x] **Test 2 (Schema Enforcement):** Response always contains `verdict`, `confidence`, `search_query_used`, `explanation`, and `sources`.
- [x] **Test 3 (Circuit Breaker Enforcement):** Fabricated queries (e.g., non-existent asteroid names) terminate in at most 2 tool calls and under 10 seconds.
- [x] **Test 4 (Source Grounding):** `sources` contains only URLs retrieved from search snippets.
